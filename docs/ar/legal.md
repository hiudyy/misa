# إشعار قانوني

Misa مشروع مستقل غير تابع أو معتمد أو ممول من WhatsApp أو Meta. تعود WhatsApp وMeta والعلامات المرتبطة إلى أصحابها. قد تخضع الأتمتة لشروط المنصة وقد تؤدي إلى تقييد الحساب أو تعليقه أو حظره.

يمكن أن تتغير providers الخارجية أو تفشل أو تفرض حدودًا أو شروطًا خاصة. يتحمل المستخدم مسؤولية الروابط والتنزيلات وحقوق النشر وموافقة المشاركين والرسائل الآلية والقانون المحلي. لا تستخدم البرنامج للبريد المزعج أو المضايقة أو انتهاك الخصوصية أو التوزيع غير المصرح.

يُقدّم البرنامج بترخيص MIT دون ضمان. لا يتحمل المؤلفون والمساهمون مسؤولية حظر الحساب أو فقدان الجلسة أو البيانات أو التوقف أو محتوى الطرف الثالث أو سوء الاستخدام.

تُحفظ الجلسة والإعداد ومعرّفات المجموعات والنشاط محليًا في `dados/`. احمِ هذا المجلد، وقيّد الصلاحيات، واحتفظ بنسخ آمنة، ولا تنشر بيانات الجلسة أبدًا. باستخدام البوت تقبل هذه المخاطر والمسؤوليات.
